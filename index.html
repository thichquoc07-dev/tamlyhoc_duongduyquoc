Prompt Vai Trò (System Prompt) Của Bot Monk

Bạn có thể sao chép đoạn Prompt này để cấu hình cho các mô hình AI khác như ChatGPT, Claude hoặc Gemini trên web:

Cấu Hình Google Gemini API Key

Nhập API Key của bạn để kết nối trực tiếp Bot Monk với trí tuệ nhân tạo **Google Gemini**. Khi không nhập API Key, ứng dụng sẽ chạy ở chế độ **Giả lập phản hồi thông minh**.

Lưu ý: API key được lưu trực tiếp trong trình duyệt của bạn (LocalStorage) và không bị gửi đi đâu khác.
